# Public content and reporting

GitHub Pages repositories, documents, assets, and commit history are public. This tool does not provide access control or confidentiality detection. Its credential patterns are limited tripwires. Review the content, source code, relative assets, and file metadata before publishing.

If a credential was published, revoke or rotate it immediately. Removing it from the latest commit does not remove public history, caches, or copies.

Do not report a vulnerability by posting actual credentials or private documents in a public issue. A public distribution repository and private reporting channel have not been configured in this draft. Contact the owner through an existing private channel, or use the distribution repository's private vulnerability reporting if enabled later. Include a synthetic reproduction and affected version.
